`TOP902 + UM980 + RTK/4G`

另外：

### 激光雷达和毫米波雷达

虽然中文都叫“雷达”，但原理完全不同。

**激光雷达：**

> 发激光 → 打到墙上 → 反射回来 → 算距离

优点是点云比较精细，很适合地图、SLAM。

**毫米波雷达：**

> 发毫米波无线电 → 反射回来 → 算距离、速度、角度

它对黑暗、强光、雾、灰尘通常比视觉更稳，还能利用多普勒测速度，但点云一般没有激光雷达那么细。

所以我们老师之前说的那套如果真的都有，实际上可能是：

```text
轮速
+
IMU
+
北斗/RTK（UM980）
+
LiDAR
+
UWB
+
毫米波雷达
+
双目
+
事件相机
```

这是**七八种不同来源**，不是几个名字指同一个东西。

因为 **UM980 绝对不能被文档写成 UWB**，这个一眼就会被懂行的人看出来。
